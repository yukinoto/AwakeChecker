# AwakeChecker

在这台常开的 Windows 电脑上判断人是否在屏幕前：看最近有没有键盘或鼠标操作，以及是否锁屏。在线时段和 MCP 查询记录写在本机 SQLite 里，重启还在。

## 启动

双击 `awake-checker.exe`，或在命令行里直接运行它。进程会立刻脱离终端，命令行可以继续做别的事，关掉窗口也不会把它带走。已经在运行时再启动一次，只会打开网页。

开发时如果想附着在当前终端：

```text
awake-checker.exe --foreground
```

网页和 MCP 只监听本机，默认是 <http://127.0.0.1:4737>。可以用 `AWAKE_BIND` 改成别的回环地址。数据库在 `%LOCALAPPDATA%\AwakeChecker\awake.db`，可以用 `AWAKE_DB` 指定文件路径。

托盘图标上：

- 左键，或右键「查看日志」：另开一个窗口回放并跟随日志。关掉这个窗口不会退出程序，再打开会重新显示。
- 右键「打开界面」：用浏览器打开网页。
- 右键「退出」：结束程序，并把当前时段收尾写盘。

## 在线策略

网页的「策略」里可以改：

- 空闲超过多少秒算离开，默认 180 秒。
- 锁屏是否立即算离开，默认是。
- 回到电脑后要连续多少秒才记为在线，默认 5 秒，用来忽略误触。

## MCP

在「接入」里创建客户端，勾选它能看到的信息。Token 只显示一次。查询记录会留下来。

范围：

- `status`：当前是否在线
- `since`：当前这段从何时开始
- `idle`：空闲秒数和是否锁屏
- `history`：时段明细
- `summary`：一段时间的在线总秒数，不含每段起止

Cursor 配置示例：

```json
{
  "mcpServers": {
    "awake": {
      "url": "http://127.0.0.1:4737/mcp",
      "headers": { "Authorization": "Bearer awk_..." }
    }
  }
}
```

工具：`get_status`、`list_sessions`、`summarize_presence`。没有对应范围的工具不会出现；硬调用会记一条拒绝记录。
